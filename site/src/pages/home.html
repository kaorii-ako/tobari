Chromium browser for Linux · CEF 154 · pre-release

A browser that closes over the window.

Tobari is a privacy-first browser built on Chromium through CEF. It blocks ads and trackers before they load, sends nothing home, and publishes what it measured, including where the savings come from and what they cost.

Caveats

This is a single run against live sites, so treat it as one observation, not a distribution. The gap against Chrome is not all efficiency: Tobari has no extension system, sync, Safe Browsing, translate or prefetch yet, and some of the difference is those missing features. 01 · Index

What is in the build

Phase 1 is a browser shell on CEF. These are the parts that exist today, each with the document that backs it.

  1. 01

    Blocking before load

    adblock-rust, the engine Brave ships, is linked into the browser and cancels ad and tracker requests before they load. Lists: EasyList and EasyPrivacy, and uBlock Origin's filters and privacy lists. Pages you navigate to directly are never blocked.

    DESIGN § Blocking
  2. 02

    Nothing sent home

    Filter list updates are plain requests with no cookies, no query string and no identifier, and SHA256SUMS records what was installed. Blocking can be turned off per site from the omnibox shield.

    SECURITY § Blocking
  3. 03

    Site isolation kept

    The Chromium sandbox stays on. The one memory lever left, --process-per-site, weakens site isolation, so it is not used.

    BENCHMARKS § Phase 2
  4. 04

    The tab strip is the title bar

    A frameless window whose whole chrome is 72px tall, with no OS title bar above it. Counting the title bar it replaces, about 40px of page height comes back. Scheme, bang and block count sit inline in the omnibox so it never needs a second row.

    DESIGN § Density
  5. 05

    Idle means idle

    The animation ticker sleeps when nothing moves. Measured, that took idle CPU from 8.00% to 0.50% of one core. Smooth scrolling and the animated new-tab background are off by default because both cost idle CPU.

    DESIGN § Performance
  6. 06

    Contrast is measured

    Every colour that carries information clears WCAG AA against every surface it can sit on, in both themes. Every control has a visible keyboard focus state.

    DESIGN § Contrast
  7. 07

    Local by default

    Bookmarks, history and the reading list are JSON files under $XDG_DATA_HOME/tobari/. DuckDuckGo-style !bangs resolve in the browser. The interface fonts are bundled, so drawing the chrome makes no network request.

    CHANGELOG

Blocking is not an anonymity feature. It reduces what third parties receive; it does not make you unidentifiable to the sites you visit.

SECURITY § Network-layer blocking
  • What it does not claim
  • Not all of the 11.9% is efficiency. Some of it is features Tobari does not have yet. Benchmarks
  • Blocking removed one process, not several. Most of the saving was resources never fetched, not renderers never created. Benchmarks
  • No Chrome extensions in this configuration. A CEF window that hosts real multi-tab cannot host Chrome-style views. That is the open question for Phase 1. README
