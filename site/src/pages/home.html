The private browser your AI agents can drive.

Tobari is a fast browser for Linux and Windows with an assistant that runs on your own model, a command bar that does maths and bangs, and a built-in MCP server so Claude Code or Cursor can read, click and screenshot your tabs. No account. No telemetry.

Not just a browser

Agents drive it

Run tobari mcp and any MCP client gets tabs, read, click, fill and screenshot. Every agent action shows a toast, and built-in pages are off limits.

Your model, your machine

Point the assistant at Ollama, llama.cpp or LM Studio, or add your own API key. Nothing is sent until you ask, and the header says where it goes.

Ask across tabs

Tick “All tabs” and question up to eight open pages at once. The answer names the page it came from. Page text is treated as data, never as orders.

A command bar that computes

Alt+K searches tabs, history and commands. Type 12*(3+4), 5 km in mi or 100 c to f, or use bangs like !gh and !wth.

Screenshot and annotate

Capture a page, then draw with pen, box and arrow, or pixelate what you want hidden. Copy it or save a PNG. All of it happens on your computer.

Private by default

Tracker blocking, HTTPS-only mode and separate-login profiles. Hold Burn to wipe cookies, cache and history in one go. Copy links with the tracking stripped.

For agents

Give Claude Code a real browser, on your terms.

One line adds Tobari to your agent: claude mcp add tobari -- Tobari.AppImage mcp. It talks to the running browser over a private socket that only your user can open.

There is no approval prompt yet, so run only agents you trust. Clicks and typing are synthetic page events, which sites that check for real input will ignore.

Split view, workspaces, a command bar

Two pages side by side, named workspaces in the dock, Alt+K for everything, and tabs that sleep when idle to free memory.

Where it stands

Works now

  • Tabs, workspaces, split view, sleeping tabs, profiles, import
  • Assistant with ten skills, local or your own key, and an All tabs switch
  • MCP server, command bar maths, screenshot and annotate, Burn, reopen closed tabs
  • Japanese and Thai render correctly

Not yet

  • macOS builds, and a signed Windows installer
  • An approval prompt for agents
  • Sync, extensions, and currency conversion
  • Published memory and speed numbers. We only quote what the repo's benchmarks show.
