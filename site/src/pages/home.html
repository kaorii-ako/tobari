What it does

Local by default

Qwen3 4B on llama.cpp, Vulkan. It loads when you ask and unloads after five idle minutes so your VRAM comes back. The header always says where your prompt goes.

Asks before it acts

The agent can read, click, type and navigate. Anything that changes a page shows a preview card first. Buying, sending and deleting always ask, even on sites you trust.

Pages can't give orders

Page text is wrapped as untrusted data and can never trigger a tool. Steps that would leak a page's contents to another site are blocked outright.

@ anything

Add the current tab, every tab, a selection, a picked element, a screenshot, a PDF, a file, bookmarks or history to a question.

Skills you can read

A skill is a folder with a SKILL.md. Ten ship with Tobari, from explaining a pull request to translating Japanese and Thai. Any prompt can become one.

Memory in Markdown

Notes live as plain files in ~/.local/share/tobari/memory. Search them, edit them in any editor, export them. They are never uploaded.

The safety check, working

A page tried to make it leak a code. It didn't.

The test page hides an instruction telling the assistant to send a secret to another site. In the test, a stand-in model is scripted to obey it. Tobari's rules found the page's own text inside the proposed URL and refused the step before it ran.

From extension/scripts/ui-e2e.mjs, one of 24 checks that run in real Chromium on every change.

Split view, workspaces, a command bar

Two pages side by side, named workspaces in the dock, Alt+K for everything, and tabs that go to sleep when idle to free memory.

Where it stands

Works now

  • Assistant, agent, skills, memory and import, as a Chromium extension plus the tobari core
  • Local model sidecar with checksummed downloads
  • Ollama, OpenAI-compatible, Anthropic and Google with your own keys, stored in the keyring
  • The tobari CLI: tabs, skills, memory, chat

Not yet

  • The standalone browser window (the CEF shell) has not been compiled
  • No v2 release to download; it runs from source
  • Japanese and Thai rendering not yet confirmed on Bazzite
  • No memory figures from target hardware yet, so none are claimed
