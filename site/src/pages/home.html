Chromium browser for Linux · CEF {{cef_major}} · pre-release

A browser that closes over the window.

Tobari is a privacy-first browser built on Chromium through CEF, in Chromium's own window, with Chrome extensions from the Web Store. It blocks ads and trackers before they load, sends nothing home, and publishes what it measured, including where the savings come from and what they cost.

01 · Index

What is in the build

Phase 1 is a browser on CEF, built and packaged. These are the parts that exist today, each with the document that backs it.

  1. 01

    Chromium's own window

    Tobari uses CEF's Chrome-style window: Chromium's tab strip in the title bar, its omnibox and its extension toolbar, themed dark and grayscale on first run. An earlier build drew its own interface in HTML; CEF cannot give that interface real tabs and Chrome extensions at the same time, so it was replaced.

    DESIGN § Where the design lives
  2. 02

    Blocking before load

    adblock-rust, the engine Brave ships, is linked into the browser and cancels ad and tracker requests before they load, in every tab. Lists: EasyList and EasyPrivacy, and uBlock Origin's filters and privacy lists. Pages you navigate to directly are never blocked. Blocking is network-level only: no cosmetic filtering.

    SECURITY § Blocking
  3. 03

    A switch in the toolbar

    Blocking is controlled by a bundled extension pinned to the toolbar. Its badge shows how many requests were blocked on the current page; its popup switches blocking off for a site, and that choice persists. It talks to the browser over a bridge that answers only that extension and refuses web pages.

    SECURITY § Toolbar extension
  4. 04

    Chrome extensions

    The Chrome Web Store works. Bitwarden and uBlock Origin Lite were installed from the store in testing. Extensions you install are kept current by Chromium's extension updater, which tells Google which extensions you have; if you install none, it does not run.

    SECURITY § Extensions
  5. 05

    Nothing sent home

    On an idle fresh profile, the only requests that leave the machine are the four weekly filter-list downloads, sent with no cookies, credentials or query string. Chromium's own calls to Google — the component updater, network time, an account check — were found in a network log and redirected to a closed local port or disabled.

    SECURITY § Contacts
  6. 06

    Local bangs, quiet defaults

    DuckDuckGo-style !bangs are resolved on your machine, so the search engine never sees a bang query. First run sets DuckDuckGo, no search suggestions, no network prediction, third-party cookies blocked and Translate off; anything you change afterwards stays changed.

    SECURITY § Defaults
  7. 07

    Sandbox always on

    Chromium's sandbox is on in every build and package; Tobari never passes --no-sandbox. The Flatpak sandboxes renderers through zypak. The per-user installer refuses to install where unprivileged user namespaces are disabled.

    SECURITY § Sandbox
  8. 08

    Surfaces drawn to a system

    The new-tab page and the blocking popup use one token set, bundled IBM Plex and a single vermilion signal. Every colour that carries information clears WCAG AA in both themes, and the animation ticker sleeps when nothing moves.

    DESIGN § Contrast

Blocking is not an anonymity feature. It reduces what third parties receive; it does not make you unidentifiable to the sites you visit.

SECURITY § What is not protected
  • What it does not claim
  • Not anonymous. Your IP address is visible, and sites can fingerprint the browser; Tobari spoofs nothing. Security
  • Not all of the 29.5% is efficiency. Part of the gap is features Tobari does not have: Safe Browsing, sync, Google account integration. Benchmarks
  • No phishing warnings. Safe Browsing is off. Tobari will not warn you before you open a known phishing or malware site. Security
  • Not always current. A Chrome security fix reaches Tobari only after CEF ships it. The current gap is below. Engine currency

Where it runs

Linux
Phase 1, built and packaged
Built and measured on Bazzite under Wayland. The Flatpak builds and runs with Chromium's sandbox working; a per-user installer writes only under your home directory. No published release yet: build from source. Packaging
