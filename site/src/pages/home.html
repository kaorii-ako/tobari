A browser that closes over the window.

Tobari is Chromium, with its own tabs and the Chrome Web Store, made to block ads and trackers before they load, send nothing home, and switch off the riskiest parts of the engine by default. Every claim it makes is measured and linked.

    03 · Index

    What is in the build

    Each part, with the document that backs it.

    1. 01

      Blocking before load

      adblock-rust, the engine Brave ships, is linked into the browser and cancels ad and tracker requests before they load: in every tab, and in service workers. Lists: EasyList and EasyPrivacy, and uBlock Origin's filters and privacy lists. Network-level only: no cosmetic filtering.

      SECURITY § Blocking
    2. 02

      Hardened by default

      V8's optimizing compilers, where most exploited Chrome bugs of recent years live, are off unless you allow them for a site. HTTPS-Only mode is on. USB, serial, HID, Bluetooth, sensors and local-font access are blocked. Extensions that Linux packages push system-wide are not installed.

      SECURITY § Defaults
    3. 03

      Nothing sent home

      On an idle fresh profile, the only requests that leave the machine are the four weekly filter-list downloads, with no cookies or query string. Chromium's own calls to Google — component updater, network time, an account check — were found in a network log and shut off.

      SECURITY § Contacts
    4. 04

      Quiet defaults

      DuckDuckGo, no search suggestions, no network prediction, third-party cookies blocked, WebRTC limited to the public interface, Translate off. Anything you change afterwards stays changed.

      SECURITY § Defaults
    5. 05

      Sandbox always on

      Chromium's sandbox runs in every build and package; Tobari never passes --no-sandbox. The Flatpak sandboxes renderers through zypak; the per-user installer refuses systems where user namespaces are disabled.

      SECURITY § Sandbox
    6. 06

      Signed releases

      Every release's checksums are signed with minisign. The installer carries the public key and refuses a download whose signature or checksum does not match, using minisign or plain OpenSSL.

      RELEASING § Signing
    7. 07

      The engine, watched

      A daily job compares Tobari's Chromium with Chrome stable and opens an issue listing any security fix Tobari lacks. The commitment is a release within three days of a CEF build that carries it.

      Engine currency, below
    8. 08

      Drawn to a system

      The new-tab page and the toolbar popup share one token set, bundled IBM Plex and a single vermilion signal. Every colour that carries information clears WCAG AA, and nothing animates when nothing moves.

      DESIGN § Contrast

    Blocking is not an anonymity feature. It reduces what third parties receive; it does not make you unidentifiable to the sites you visit.

    SECURITY § What is not protected
    • What it gives up
    • Not anonymous. Your IP address is visible, and sites can fingerprint the browser; Tobari spoofs nothing. Security
    • No phishing warnings. Safe Browsing is off. Tobari will not warn you before a known phishing or malware site. Security
    • Heavy JavaScript is slower. With the optimizer off, a JavaScript benchmark ran 2.1× slower. One switch per site gives it back. Security
    • Not always current. A Chrome security fix reaches Tobari only after CEF ships it. Engine currency

    04 · Install

    Three ways in

    All three install for your user only and keep Chromium's sandbox on. Updating is running the same thing again.

    curl -fsSL {{install_url}} | bash

# options
curl -fsSL {{install_url}} | bash -s -- --tarball --set-default
curl -fsSL {{install_url}} | bash -s -- --uninstall

    Downloads release {{version}} from GitHub, checks SHA256SUMS.minisig against the pinned key and the artifact against SHA256SUMS, then installs. Prefer to read first? The script is short.

    V={{version}}; U={{release_dl}}
curl -fLO $U/tobari-$V.flatpak -O $U/SHA256SUMS -O $U/SHA256SUMS.minisig
minisign -Vm SHA256SUMS -P {{pubkey}}
sha256sum -c --ignore-missing SHA256SUMS
flatpak install --user tobari-$V.flatpak

    The runtime comes from Flathub. The app is dev.tobari.Browser; its profile lives in ~/.var/app/dev.tobari.Browser/.

    git clone {{gh}}
cd tobari
CEF_ROOT=$(shell/provision-cef.sh | tail -1)
cmake -S shell -B build -G Ninja -DCEF_ROOT="$CEF_ROOT" -DCMAKE_BUILD_TYPE=Release
cmake --build build
packaging/install.sh build

    Needs CMake, Ninja, a C++20 compiler and Rust. On immutable systems, build inside a distrobox container. Developing on Linux

    06 · Questions

    Asked first

    Is this a fork of Chromium?

    No. Tobari embeds Chromium through CEF, the framework Spotify and Steam use, and drives Chromium's own browser window. It changes behaviour from outside the engine: request handling, preferences and launch switches. That keeps it small enough to follow Chromium releases closely, at the cost of waiting for CEF to ship each one. Design

    Will my Chrome extensions work?

    Extensions from the Chrome Web Store install with Chromium's permission prompt and update normally. Bitwarden and uBlock Origin Lite were installed and used in testing. Extensions that need a Google account sign-in to the browser itself, such as Chrome sync, do not apply: Tobari has no browser account.

    Why is a site slow? Why does a site break?

    Heavy web apps and games can be slower because V8's optimizing compilers are off by default. Open the Tobari toolbar popup and turn on Fast JavaScript for that site. If a site breaks, turn Blocking off for it in the same popup; both choices are remembered per site. Why the optimizer is off

    Does it update itself?

    Not yet. Tobari makes no update checks of its own, because it contacts nobody but the filter-list hosts. Run the installer again to update, and watch GitHub Releases for new versions. Filter lists and Web Store extensions do update themselves.

    Where is my data, and can I bring my Chrome profile?

    Everything stays on your machine: ~/.local/share/tobari for the per-user build, ~/.var/app/dev.tobari.Browser/ for the Flatpak. Bookmarks and passwords can be moved with Chromium's own import (Settings → Import bookmarks and settings) or an HTML or CSV export.

    macOS or Windows?

    Linux only. macOS is not a Phase 1 target, because there is no Mac to test on and no way to notarize a build. Windows is out of scope. Why

    How do I remove it?

    curl -fsSL {{install_url}} | bash -s -- --uninstall removes either install and leaves your profile in place, so you can delete that yourself.
