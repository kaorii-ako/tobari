Install

Run Tobari on Linux

Tobari {{v2_version}} (v2 preview) runs as the Tobari extension plus the tobari core inside Chromium. One command installs it for your user only, after checking the release signature and checksum.

curl -fsSL https://kaorii-ako.github.io/tobari/install-v2.sh | bash

Then tobari-browser starts it, or pick Tobari from your app menu. tobari setup downloads the local model.

On Bazzite or another atomic system, run the command inside a distrobox container with Chromium: distrobox create --name tobari --image registry.fedoraproject.org/fedora-toolbox:42, distrobox enter tobari, sudo dnf install -y chromium. The Flatpak Chromium and Brave can't run the Tobari core.

Remove it with curl -fsSL https://kaorii-ako.github.io/tobari/install-v2.sh | bash -s -- --uninstall. Read the script first.

Or build from source

Tobari v2 has no published release yet. Today it runs as the Tobari extension plus the tobari core inside Chromium, built from source in a distrobox container. Nothing touches your host system. Once the 0.5.0 preview is published, a one-line installer appears here.

  1. Create a container

    On Bazzite, Silverblue or any Fedora Atomic system, build tools go in a container.

    distrobox create --name tobari --image registry.fedoraproject.org/fedora-toolbox:42
distrobox enter tobari

  2. Install the toolchain

    sudo dnf install -y git gcc gcc-c++ cmake ninja-build nodejs npm python3 chromium libsecret
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y

    This sudo runs inside the container, not on your host.

  3. Get the code and start it

    git clone https://github.com/kaorii-ako/tobari
cd tobari
scripts/dev-run.sh

    This builds the core and the extension, registers the core with Chromium, and opens Chromium with Tobari loaded and its own profile in ~/.config/tobari/browser.

  4. Download the local model

    core/target/release/tobari setup

    Asks first, then fetches llama.cpp's Vulkan build and Qwen3 4B Instruct (about 2.4 GB), each checked against a pinned SHA-256. Skip it if you'd rather use a cloud provider with your own key in Settings.

  5. Use it

    Alt J opens the panel, Alt K the command bar. Type @ to add context and / for skills.

Why not Flatpak Chrome or Brave? Their sandbox can't start a program outside it, so the assistant can't reach the core. Use the container's Chromium until the Tobari Flatpak exists.
