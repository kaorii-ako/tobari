01 · Installer

What the command does

It is a short bash script. Read it before you pipe it into a shell; that is what it is there for.

  1. Checks the machine

    Linux on x86_64, run as your own user and not root. With Flatpak present it installs the Flatpak; otherwise the per-user build, after checking that unprivileged user namespaces work, because Chromium's sandbox needs them and Tobari will not run without its sandbox.

  2. Downloads release {{version}} from GitHub

    SHA256SUMS, its signature SHA256SUMS.minisig, and the one artifact it needs, over HTTPS only.

  3. Checks the signature, then the checksum

    The release key is written into the script. It verifies the signature with minisign if you have it, or with OpenSSL 3, which can check minisign's Ed25519 signatures directly. Then it checks the artifact's SHA-256 against the signed list. Either failure stops it before anything is installed.

  4. Installs for you only

    The Flatpak goes into your user installation (flatpak install --user), with the runtime from Flathub. The per-user build goes into ~/.local/lib/tobari with a launcher in ~/.local/bin and a menu entry. Nothing outside your home directory changes, so it works on immutable systems like Silverblue and Bazzite.

02 · Options

Choices

optiondoes
--flatpakInstall the Flatpak bundle. The default when flatpak is installed.
--tarballInstall the per-user build into ~/.local, no Flatpak needed.
--set-defaultMake Tobari the default web browser. Never done unless asked.
--version X.Y.ZInstall a specific release.
--uninstallRemove either install. Your profile is kept.
 
curl -fsSL {{install_url}} | bash -s -- --tarball --set-default

To update, run the installer again. Tobari does not check for updates itself, because it contacts nobody but the filter-list hosts; watch Releases for new versions.

03 · By hand

Verify and install without the script

The same steps the installer takes, one at a time.

  1. Get the public key from two places

    It is committed to the repository and served by this site, so one copy can be checked against the other.

    Key id
    0F0DC333B8A4E968
    Public key
    {{pubkey}}
    Repository
    tobari.pub
    This site
    /tobari.pub

  2. Download

    V={{version}}; U={{release_dl}}
curl -fLO $U/SHA256SUMS -O $U/SHA256SUMS.minisig \
     -O $U/tobari-$V.flatpak -O $U/tobari-$V-linux-x86_64.tar.gz

  3. Check the signature, then the checksums

    minisign -Vm SHA256SUMS -P {{pubkey}}
sha256sum -c --ignore-missing SHA256SUMS

    If minisign does not report the signature as verified, the download is not Tobari. Stop, and open an issue.

  4. Install one of them

    # Flatpak
flatpak install --user tobari-$V.flatpak

# or the per-user build
tar xzf tobari-$V-linux-x86_64.tar.gz
tobari-$V/install.sh tobari-$V/app

04 · Source

Build from source

Every build tool lives in a distrobox container; nothing is layered onto the host. The steps follow DEV-LINUX.

  1. Create the container and install the toolchain

    distrobox create --name tobari --image registry.fedoraproject.org/fedora:41
distrobox enter tobari
sudo dnf install -y git cmake ninja-build gcc-c++ python3 python3-pillow openssl \
  gtk3-devel libX11-devel libXi-devel nss-devel alsa-lib-devel \
  at-spi2-atk-devel cups-devel libdrm-devel mesa-libgbm-devel
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y

    Rust is needed because the blocking engine is a Rust library that CMake builds with Cargo.

  2. Clone, provision CEF, build

    git clone {{gh}} && cd tobari
CEF_ROOT=$(shell/provision-cef.sh | tail -1)
cmake -S shell -B build -G Ninja -DCEF_ROOT="$CEF_ROOT" -DCMAKE_BUILD_TYPE=Release
cmake --build build

    shell/provision-cef.sh downloads the pinned CEF build ({{cef_version}}), checks it against the hash pinned in the script and caches it in ~/.cache/tobari-dev/. One build produces the blocking engine, the tobari binary, both bundled extensions and the filter lists.

  3. Run or install it

    build/tobari                                     # run in place
packaging/install.sh build [--set-default]       # per-user install
packaging/flatpak/build.sh build --install       # local Flatpak

    XDG_DATA_HOME=/tmp/p gives a throwaway profile; TOBARI_NO_BLOCKING=1 starts it without the blocking engine.
