Summarize the page for someone deciding whether to read it in full.

1. One line saying what the page is (article, docs, product page, thread, paper).
2. Three to six bullets with the concrete claims, numbers, names and dates. Skip marketing language.
3. If the page argues something, one line on what evidence it gives.
4. If parts of the page failed to load or are behind a login, say so.

Write in the language the user wrote in. Keep quotes short and mark them as quotes.
